# 3D-модели зданий для Яндекс Карт

Скилл для Codex, который помогает построить низкополигональную модель реального здания и проверить итоговый экспорт по фотографиям, спутниковому плану и кадрам облёта. При работе с двумя агентами моделлер отвечает за геометрию, а ревьюер сравнивает файл для отправки с реальным объектом.

## Установка

Скопируйте файл `SKILL.md` в каталог `~/.codex/skills/yandex-maps-3d/` и откройте новый чат Codex. Если каталог ещё не существует, его можно создать при клонировании:

```sh
git clone https://github.com/ai-some-skills/yandex-maps-3d.git ~/.codex/skills/yandex-maps-3d
```

## Пример

> Используй $yandex-maps-3d. Запусти моделлера и независимого ревьюера. Сверь текущую модель с фотографиями и размерами из проекта, исправь подтверждённые расхождения и дай ссылку на проверенный экспорт.

Для одного ревью попросите сравнить готовый файл с референсами и перечислить расхождения. Для новой модели приложите карточку здания, известные размеры и доступные изображения. Если модель уже есть, приложите исходник и файл для отправки.

Это независимый пользовательский скилл. Актуальные требования к моделям публикует команда [Яндекс Карт](https://yandex.ru/project/maps/3d/tech).
